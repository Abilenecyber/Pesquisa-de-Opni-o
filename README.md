# 📋 Pesquisa de Atendimento ao Cliente - TudoWeb
Este projeto foi desenvolvido como parte das atividades da disciplina de **Desenvolvimento de Sistemas I**, focada no estudo de estruturas de repetição e decisão em Python.
Situação hipotética: A empresa de marketing TudoWeb precisa realizar uma pesquisa de opinião com seus clientes para saber o grau de satisfação no atendimento.

## 🚀 Sobre o Projeto

O programa consiste em um sistema de coleta de feedback automático criado para a empresa de marketing *TudoWeb*. Ele automatiza o processo de entrevista coletando dados de clientes e gerando um relatório consolidado com os índices de satisfação ao final.

### ⚙️ Funcionalidades
* Coleta de dados básicos: Nome e Idade.
* Menu interativo de opinião (1: Excelente | 2: Bom | 3: Ruim).
* Estrutura de repetição (`for`) para automatizar as rodadas de entrevistas.
* Estrutura de decisão (`if`) para calcular e exibir de forma resumida as métricas exigidas.
